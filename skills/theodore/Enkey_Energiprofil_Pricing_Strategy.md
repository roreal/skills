# Traditionella prismodeller

## 1. Pris per lägenhet

Vanliga nivåer:
- 20–100 kr/lägenhet/månad
- 240–1200 kr/lägenhet/år

### Fördelar
- Enkel att förstå
- Enkel att budgetera
- Enkel att sälja

### Nackdelar
- Tar ingen hänsyn till energiförbrukning
- Tar ingen hänsyn till ventilationstyp
- Tar ingen hänsyn till energisystem
- Två byggnader med helt olika komplexitet får samma pris

---

## 2. Pris per m²

Vanliga nivåer:
- 3–15 kr/m² och år

### Fördelar
- Vanlig modell i fastighetsbranschen
- Enkel att jämföra

### Nackdelar
- Speglar inte faktisk energikomplexitet
- Moderna energieffektiva byggnader riskerar överprissättning
- Ineffektiva byggnader riskerar underprissättning

---

# Enkeys modell

## Energiprofilbaserad prissättning

Optimate® prissätts baserat på:
- historisk normalårskorrigerad energi
- för de system som Optimate påverkar

Detta fungerar som ett mått på:
- energirisk
- termisk komplexitet
- optimeringspotential
- ekonomiskt värde

---

# Viktig princip

Priset påverkas inte av:
- framtida energieffektivisering
- besparingar över tid

Debiteringsunderlaget fastställs:
- vid projektstart
- baserat på historisk energiprofil

Detta skapar:
- stabil ARR
- enklare budgetering
- inga konflikter kring baseline
- bättre långsiktig relation
